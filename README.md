# Resource Saver v1.0.3

稳定优先修复版。

- 弹药：启用 Terraria 原版 ammoCost80，20% 节省。
- 魔力：基础魔耗 -15%；若 HeldItem 分类成功，召唤/哨兵 -25%。
- 回魔：自然回魔累计速度 +20%。
- 治疗药水冷却：恢复速度 +10%（本版先对所有职业生效，避免 HeldItem 依赖）。
- 战斗 Buff：通过 Player.AddBuff(int,int,bool) 将支持的长 Buff 延长 20%。
- 鱼饵：启用 Terraria 原版 Tackle Box 节饵机制，优先保证手机版 1.4.5.6.4 生效。
